В ходе работы был реализован класс DataPreprocessor, выполняющий
базовую очистку и трансформацию табличных данных.

На примере датасета Titanic показано, что:
– столбцы с большим количеством пропусков (deck) корректно удаляются;
– пропуски в остальных признаках заполняются медианой или модой;
– категориальные признаки автоматически кодируются методом one-hot encoding;
– числовые признаки нормализуются с помощью Min-Max нормализации.

Также класс сохраняет информацию о применённых преобразованиях
(удалённые столбцы и итоговые one-hot признаки), что позволяет
повторно применять тот же preprocessing pipeline к новым данным.
